# TKFMaaR 1.5

**本版修复了很多 bug，但仍不能保证完整跑通。** 不同账号、网络状态和游戏页面仍可能遇到未覆盖的情况；CI构建成功不代表整套任务已通过实机验证。

## 主要改动

- 异常恢复改为正常识别未命中后立即检查已知异常，命中明确异常才操作；连续20秒都无法识别时再尝试返回及原暂停／重启策略。增加登录网页无法打开的识别；服务器异常需要复核正文，避免普通“提示／确定”弹窗被误当作掉线。
- 奖励领取按页记录请求和响应，处理仓库堆叠上限及换行文字，减少领取后误入登录恢复或误判完成；修正领奖前角色强化的点击调用。
- 调教按实际加成、进度、库存和现有点数计算安全批次，连点后核对消耗再补漏点，移除20秒动画等待。修复“全部点数”被误读成默认3次；只处理当前房间，仍可能因房间已满、无安全道具或防溢出而提前结束。禁止桃子、高价值道具、购买和补充资源。
- 炼金首页抽屉入口改为固定屏幕比例点击，避免角色背景导致箭头模板失效；沿用空栏补999个蓝宝石及已有生产保护。
- 协会商店接入魔晶石购买，新增榨乳器图片识别和调教道具勾选项；榨乳器默认不选，沿用该组折扣和售罄保护。

## 升级与配置继承

- 自动检查更新继续使用 `RShock/TKFMaaR`。建议将完整包解压到新目录，通过首次启动迁移向导导入旧助手；导入包含 `config/`、根 `appsettings.json`、定时设置及自定义关卡截图，导入前保留备份。详情见[配置迁移](../tasks/config_migration.md)。
- 已保存的任务选择、次数、调教目标、购买清单、折扣开关及其他有效选项继续沿用，包含用户明确取消和全部不选的状态；不会用整套新版默认值覆盖旧设置。
- 只有新增项使用默认值：新接入的魔晶石默认勾选，榨乳器默认不选。洪水之石和匕首等旧商品尊重已有选择；新建配置中洪水之石、匕首和魔晶石默认勾选。
- 禁止桃子及高价值道具属于本版固定资源保护，旧“允许使用珍贵调教道具”选项不再生效。个人配置、日志和自定义截图不会打入公共发布包。

## 验证范围
