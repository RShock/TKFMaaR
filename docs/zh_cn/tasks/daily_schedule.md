# 配置定时任务

在“启动游戏”中配置定时任务和模拟器启停。任务行的灰底白勾表示始终勾选，点击任务名称可打开设置。

- **定时任务允许自动启动模拟器**在需要时启动已选的模拟器。助手有已保存的启动程序时会沿用，也可根据支持的设备信息自动识别。
- **定时任务执行完毕后关闭模拟器**在队列成功完成且设备空闲时关闭实例。当前支持 MuMu 和 Android Emulator 的单实例关闭。其他模拟器在缺少对应关闭命令时保留运行状态。
- **自动最速派遣**根据三队中最后结束的倒计时预约下一轮。开关下方显示下次派遣时间。详见[每日派遣](daily_dispatch.md)。
- **定时执行所有日常任务**按电脑本地时间执行当前配置中勾选的任务。默认每天 17:30。可用逗号分隔多个时间，例如 `17:30, 21:30`。

“测试自动启动”在确认模拟器关闭时可点。启动后等待当前 ADB 设备就绪并报告结果，测试不运行游戏任务。

Windows 下，关闭主窗口默认会把助手收进右下角托盘，当前任务和定时任务会继续运行。双击托盘图标可恢复窗口。要彻底关闭助手，请在托盘菜单选择“退出”。

在“设置 → 界面设置”中可开启“开机自启动”。下次登录 Windows 后，助手会自动启动并收进托盘。电脑须保持唤醒，助手须保持运行。已经占用的设备等待空闲，助手关闭或休眠期间错过的时间不补跑。同一分钟只触发一次。旧的每日定时启动项迁入新面板，按周、按月及其他原生定时动作保留在原生设置中。
